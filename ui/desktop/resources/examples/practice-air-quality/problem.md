# 城市空气质量预测

## 背景

某城市环保部门连续记录了 **200 天** 的空气质量数据，字段包括气温、湿度、风速、交通拥堵指数，以及当日的 PM2.5 浓度（目标变量）。环保部门希望建立预测模型，提前预判 PM2.5 浓度，以便发布健康提示。

附件 `air_quality.csv` 为历史记录，共 200 行。

## 需要解决的问题

### 问题一：数据探索与预处理

对附件数据进行探索性分析：

1. 各变量的分布、缺失值与异常值情况；
2. 各气象/交通变量与 PM2.5 的相关性（给出相关系数或相关图）；
3. 说明你的预处理方法（缺失值填充、异常值处理、标准化等）及理由。

### 问题二：统计建模与预测

建立 PM2.5 浓度预测模型：

1. 至少建立 **两种** 预测模型（如多元线性回归、随机森林、支持向量回归、梯度提升等）；
2. 划分训练集与测试集，用合适的指标（RMSE、MAE、R²）评估并比较；
3. 给出各变量重要性排序与合理解释。

### 问题三：预测结果解释与稳健性

1. 对预测结果给出置信区间或不确定性度量；
2. 分析模型在极端天气（高温、静风）下的表现；
3. 讨论若新增"工业排放"等特征，模型应如何扩展。

## 说明

- 所有数据均为合成数据，仅用于建模练习。
- 建议固定随机种子，保证结果可复现。
