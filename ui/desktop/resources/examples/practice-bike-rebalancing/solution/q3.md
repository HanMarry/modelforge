# 问题三：多车协同与灵敏度（参考思路）

## 建模要点

1. **多车 VRP**：2 辆调度车可看作"多车场"或"单车路线分割"，用扫描法或 K-means 按地理区域划分站点后分别求解。
2. **灵敏度**：目标车辆数 `t_i` 分别 ±10%，重跑调度并比较总成本变化率。

## 分析方向

- 多车协同通常能显著缩短总行驶距离（尤其站点分布分散时）。
- 目标值上浮 10% → 搬运量增加 → 成本上升；下调 10% → 可能出现站点缺车 → 满足率下降，需权衡成本与满足率。

## 可扩展性

- 24 个站点时，精确整数规划规模可控；更大规模应改用启发式（ALNS、遗传算法）。
- 记录求解时间随站点数的增长曲线。
