# 问题二：调度路径规划（参考思路）

## 建模要点

1. **距离**：站点坐标用欧氏距离（或曼哈顿距离）计算，构造距离矩阵。
2. **目标车辆数**：由问题一得到的各站点目标值 `t_i`；搬运量 `x_ij` 为从站点 i 到站点 j 搬运的单车数。
3. **VRP 约束**：调度车总装载量 ≤ 30；每站装载前后车辆数非负；出发站与结束站车辆守恒。

## 求解思路

- 这是一个带容量约束的 VRP，可用贪心最近邻 + 2-opt 局部搜索、或整数规划（站点少时可用 Gurobi/OR-Tools 精确求解）。
- 初始解：按缺口排序，从缺口最大的站点依次搬运。

## 输出建议

- 调度路线表（起点 → 终点 → 搬运量）；
- 总行驶距离；
- 调度前后各站满足率对比柱状图。
