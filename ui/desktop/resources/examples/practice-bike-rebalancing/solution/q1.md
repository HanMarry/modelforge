# 问题一：供需缺口评估（参考思路）

## 建模要点

1. **净需求**：`demand.csv` 中 `net_demand = 借出需求 - 归还数量`。某站点某小时的净缺口为 `net_demand - 当前车辆数`（为负表示过剩）。
2. **累计缺口**：站点全天的缺口为逐小时缺口之和（只计正值或直接求和均可，需说明口径）。
3. **目标车辆数**：使全天无车可用率最低等价于让各时段车辆数 ≥ 借出需求，可用分位数法取 `初始车辆数 = max(需求累计的某个分位数, 容量约束)`。

## 参考结果方向

- 早高峰（7–9 时）与晚高峰（17–19 时）缺口最大，商业区/办公区站点方向相反。
- 初始车辆数应接近"全天净需求峰值 + 安全裕量"，且不超过站点容量。

## 输出建议

- 一张"站点 × 24 小时"的热力图；
- 缺口最大的 3 个站点及其缺口量；
- 建议初始车辆数表。
