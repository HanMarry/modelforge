# 问题一：指标预处理与赋权（参考思路）

## 无量纲化

- 正向指标可用 min-max 归一化或 z-score 标准化；
- 各指标均为正向（越大越好），无需反向处理。

## 赋权方法

1. **熵权法**：依据指标离散程度客观赋权，离散越大权重越高；
2. **AHP**：构建判断矩阵，主观赋权，需通过一致性检验；
3. **PCA**：降维后按方差贡献率赋权。

## 相关性

- 论文数与总被引次数强正相关（Pearson 相关系数约 0.83），存在信息重叠，赋权时需注意或先降维。
- H 指数与论文数、总被引次数只有弱相关（相关系数约 0.22、0.14），可以作为相对独立的指标保留；其余指标两两之间相关系数的绝对值都不超过 0.35。
