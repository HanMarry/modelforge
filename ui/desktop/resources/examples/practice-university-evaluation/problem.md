# 高校科研实力综合评价

## 背景

某评估机构需要对 **20 所高校** 的科研实力进行综合评价。附件 `universities.csv` 给出各高校的 5 项指标：论文数、总被引次数、H 指数、科研经费（万元）、获国家级奖励数。

评价面临的核心难点是：各指标量纲不同、重要性不同，且可能存在相关性，需要一套科学、可解释的综合评价方法。

## 需要解决的问题

### 问题一：指标预处理与赋权

1. 对 5 项指标进行无量纲化处理（说明所选方法及理由）；
2. 确定各指标的权重，至少使用 **两种** 赋权方法（如熵权法、层次分析法 AHP、主成分分析 PCA 等）并比较；
3. 分析指标间的相关性，判断是否存在信息重叠。

### 问题二：综合评价与排序

建立综合评价模型，给出 20 所高校的综合得分与排序：

1. 说明评价模型（如加权求和、TOPSIS、灰色关联度等）及选择理由；
2. 给出综合得分表与最终排序；
3. 分析排序结果是否稳健（如更换赋权方法后排序是否变化）。

### 问题三：结果解释与建议

1. 对排名靠前与靠后的高校，解释其得分的主要驱动指标；
2. 讨论不同赋权方法导致排序差异的原因，并给出更稳健的合成策略；
3. 若评估对象新增指标（如成果转化收入），模型应如何调整。

## 说明

- 所有数据均为合成数据，仅用于建模练习。
- 建议固定随机种子，保证结果可复现。
