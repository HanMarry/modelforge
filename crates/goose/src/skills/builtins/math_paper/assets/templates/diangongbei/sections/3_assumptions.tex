\section{模型假设}

% 写作提示：只保留模型确实需要且后文会使用的假设；每条说明依据、简化作用、适用范围和可能影响。
% 下方假设仅为示例，不得无依据地照搬“数据完全可靠、因素独立、系统稳定、变量连续可微”等表述。

为简化问题，本文做出以下基本假设：
\begin{enumerate}
    \item 假设题目所给数据真实可靠，不存在系统性的测量误差；
    \item 假设各因素之间的交互作用可以忽略不计；
    \item 假设系统在短期内处于稳定状态；
    \item 假设所有变量连续可微；
    \item 假设缺失值为随机缺失，可采用插补方法处理。
\end{enumerate}
