# Sample problems

Self-authored practice problems for the 科研绘图 / 论文模板 workflow. They exist so the
"试一试这些数模真题" cards on the home screen open something that actually runs.

They are **not** past competition papers. Real contest problems are solicited from
contributors and their redistribution terms are not stated by the organisers, so
nothing here is copied or mirrored — each problem below was written for this project
and its data is generated by the accompanying script. The dataset is synthetic and
labelled as such wherever it appears.

Each directory contains:

| File | Purpose |
|---|---|
| `problem.md` | The problem statement, in the same shape a contest problem takes |
| `generate_data.py` | Writes `data/` deterministically (fixed seed) |
| `README.md` | What the problem exercises and which skills it is meant to load |

Generate the data before starting:

```bash
uv run --with numpy --with pandas python generate_data.py
```

## Problems

| Directory | Domain | Exercises |
|---|---|---|
| `production-planning/` | Multi-objective optimisation | LP/MILP formulation, Pareto trade-offs, sensitivity |
| `demand-forecast/` | Time series | decomposition, ARIMA/SARIMA, rolling backtest |
| `water-quality/` | Evaluation and ranking | entropy weight, TOPSIS, weight-perturbation robustness |
