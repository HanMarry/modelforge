# 真实文献检索与引用

## 核心原则

**只引用真实存在且已核验的文献。** 参考文献的每一条 bib 条目必须来自
`scripts/paper_search.py bib --doi <DOI>` 的输出（由 doi.org / Crossref 权威元数据生成），
禁止凭模型记忆手写题名、作者、期刊、卷期页。宁可少引，不可编造。

## 数据源

- **OpenAlex**：结构化学术元数据，相关性检索强，带被引数。
- **Crossref**：DOI 注册机构官方数据，同时充当 BibTeX 权威来源。

两个引擎默认并行调用。DOI 相同的记录直接交叉验证合并；无 DOI 时仅在标题规范化后
相同且年份一致时合并。输出中 `✓交叉验证` 表示两个引擎同时命中，可信度最高；
单引擎结果同样真实，但引用前仍需 `verify` 核对。

## 工作流

1. **检索候选**（按每个模型/方法分别检索，组合方法名 + 领域名，如
   `entropy weight TOPSIS evaluation`、`LSTM time series forecasting`）：

   ```bash
   python scripts/paper_search.py search --query "robust optimization vehicle routing" --limit 8
   ```

   可选：`--year-from 2015 --year-to 2025` 限定年份，`--json` 输出结构化结果。
   结果过少时逐步放宽查询词，不要直接接受主题无关的结果。

2. **核验元数据**（引用前逐条执行，核对作者、题名、年份、期刊）：

   ```bash
   python scripts/paper_search.py verify --doi 10.1080/07408170701745378
   ```

3. **生成 BibTeX 并追加到 book.bib**（`--key` 指定正文 `\cite{}` 使用的引用 key）：

   ```bash
   python scripts/paper_search.py bib --doi 10.1080/07408170701745378 --key ref01 >> book.bib
   ```

   DOI 不存在时命令以非零退出并提示"可能是编造的"——此时该文献**禁止引用**。

## 筛选规则

- 相关性优先于被引量：高被引但主题无关的论文不得挤占结果。脚本已按查询词
  覆盖率过滤（多术语查询至少命中两个词），但这不能代替人工判断。
- 优先选择 `✓交叉验证`、期刊/会议明确、有 DOI 的记录。
- 无 DOI 的记录（部分中文文献、教材、标准）只能在人工打开出版机构页面核对后
  引用，且 bib 条目字段必须逐项来自该页面，不得脑补。

## 中文文献

OpenAlex / Crossref 对 CNKI 中文期刊覆盖有限。检索中文主题时优先用对应英文
术语检索国际文献；确需引用中文文献而检索不到时，明确告知用户"未能自动核验"，
由用户提供出处，绝不编造中文文献条目。

## 核验规则（不可跳过）

1. 搜索结果只用于发现候选文献，不等于可直接引用。
2. 每条引用前必须 `verify`（或打开 DOI 页面）核对作者、题名、年份、期刊、卷期页。
3. 被引量不是正确性证明，不据此断言结论。
4. 不根据标题或摘要编造论文中不存在的结论；引用处的表述必须与文献主题相符。
5. 网络不可用或所有引擎失败时：如实告知用户，减少引用数量，**绝不**用编造的
   条目占位。
