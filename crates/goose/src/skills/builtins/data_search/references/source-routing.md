# 数据来源路由与质量评估

这些站点是检索起点，不是永久可用性承诺。每次任务都要打开当前官方页面，核验数据集、版本、许可和下载方式。

## 来源路由

| 领域 | 优先原始来源 | 补充来源 | 常见注意点 |
| --- | --- | --- | --- |
| 中国综合统计 | 国家统计局“国家数据”、统计年鉴、各部委及地方政府开放数据平台 | 高校数据平台、研究仓库 | 指标口径和行政区划可能跨年变化；年鉴表格常需整理 |
| 国际宏观与人口 | World Bank、UN Data、OECD、IMF、Eurostat、ILOSTAT | Our World in Data、Data Commons | 二手整合数据要追溯原始指标；核对国家代码和不变价基期 |
| 健康与公共卫生 | WHO GHO、各国卫生主管部门、CDC 等官方机构 | IHME、论文附属数据、领域仓库 | 年龄标化、病例定义和隐私限制会影响可比性 |
| 农业与食品 | FAOSTAT、农业主管部门 | World Bank、研究仓库 | 区分产量、单产、播种面积和贸易量；检查单位换算 |
| 气象与气候 | 中国气象数据网、NOAA NCEI、Copernicus CDS/ERA5、NASA Earthdata | 区域站点、Zenodo | 站点/格点、时区、空间分辨率、再分析与观测不能混用 |
| 地理与遥感 | 国家/地方测绘开放数据、USGS、Copernicus、NASA、OpenStreetMap、Natural Earth | Geofabrik、研究仓库 | 坐标系、边界年份、分辨率和 ODbL/其他许可必须保留 |
| 环境与能源 | 生态环境主管部门、EIA、EPA、IEA 的开放部分 | Ember、研究仓库 | 监测方法、排放核算边界和付费数据边界可能不同 |
| 交通与城市 | 交通主管部门、城市开放平台、GTFS 发布者、OpenStreetMap | Kaggle、论文附属数据 | 路网许可、轨迹隐私、时段覆盖和采样偏差 |
| 学术通用数据 | Zenodo、Figshare、Dryad、Dataverse、OSF、论文 Data availability | 学科数据库 | 用 DOI/版本固定数据；核对作者上传内容与论文描述 |
| 机器学习基准 | UCI、OpenML、Hugging Face Datasets、原论文仓库 | Kaggle | 识别镜像、竞赛加工版、标签泄漏和训练/测试划分 |
| 生物医学与组学 | NCBI GEO/SRA、EBI、UniProt 等领域权威库 | ToolUniverse、论文附属数据 | 物种、组织、平台、处理流程和样本注释必须匹配 |

## 查询组合

从数据契约生成多组查询，不要只搜一句自然语言：

- `指标 地区 年份 数据 下载 CSV`
- `指标 发布机构 API metadata`
- `site:gov.cn 指标 filetype:xlsx`
- `site:org dataset 指标 地区 时间范围`
- `论文题名 data availability dataset DOI`
- `指标 definition methodology codebook`

同时尝试官方指标名、常用简称、英文名、旧称和可能的代理指标。对中国数据优先搜索中文原名，对国际来源优先搜索英文官方名。

## 质量评分

用评分帮助排序，但不要用总分掩盖致命缺陷。

| 维度 | 分值 | 判断 |
| --- | ---: | --- |
| 权威性 | 0–3 | 原始发布者 3；可信学术仓库 2；可追溯聚合 1；来源不明 0 |
| 题目适配 | 0–3 | 变量、口径、地区、时间和粒度的匹配程度 |
| 完整性 | 0–2 | 覆盖、缺失、样本规模和版本说明 |
| 可获取性 | 0–1 | 机器可读、稳定下载/API、规模合理 |
| 许可清晰度 | 0–1 | 许可和署名要求明确 |

以下情况直接降级或淘汰：

- 只有搜索摘要，打不开落地页；
- 数据标题相似但指标定义不一致；
- 无法确认发布者或原始出处；
- 只有图片/PDF 表格且存在更好的机器可读来源；
- 许可明确禁止当前用途；
- 数据严重过时，却被当作当前状态；
- 聚合站修改了原始值但没有方法说明。

## 核验记录

对最终采用的数据至少保留：

- 官方数据集标题与发布者；
- 落地页 URL 与实际文件/API URL；
- 检索和获取日期；
- 指标定义、单位、时间/地域范围和粒度；
- 版本或更新时间；
- 许可证/使用条款页面；
- 文件 SHA-256 与本地相对路径；
- 已知缺失、口径变化、代理指标和处理说明。
